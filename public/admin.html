團隊與審核設定

通過条件：邀請歸屬符合、KYC 完成、已入金。不設最低金額，也不要求 LINE 帳號持有證明。同一 UID 不重複發送。

系統如何運作

  1. 用戶在 LINE 提交 UID
  2. BingX 核對邀請關係、KYC 與入金
  3. 資格通過後自動送出社群連結
  4. 客服確認入群，持續同步每日資料

API 憑證由部署環境的秘密設定提供，頁面只顯示是否已設定。每個團隊使用獨立的 Worker、資料庫與 LINE 官方帳號。

同步範圍

每日重整最近 60 天的交易量、佣金及入金明細；保留已同步的歷史交易資料。尚未通過的 UID 約每 15 分鐘複查，更新延遲以交易所為準。

VIP 的「LINE 已接受」與「已確認入群」分開記錄。行銷推播仍需用戶訂閱，並由你預覽確認。
