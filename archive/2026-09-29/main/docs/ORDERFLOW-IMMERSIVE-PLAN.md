# 訂單流學院：漸進式沉浸教學

## 教學原則

- 不以學員已經認識英文縮寫為前提。先呈現一件能觀察的事，再讓學員操作，最後替現象命名。
- 每個畫面只有一個主要行動。名詞、數值及圖層到需要時才揭露，不預先展示整個交易工作台。
- K 線與訂單共用畫布、價格座標與鏡頭；100 的初始成交從第一幕即存在。
- 切換觀察方式時保留 K 線旁的價格參照，掛單與結論交疊淡入淡出；展開逐價紀錄時，K 線、刻度與紀錄共用連續縮放，讓學員能追蹤同一段成交。
- 掛撤單、真正成交、合約存量與持倉費用分開呈現。圖上的數值來自同一個模型，不能為了故事另外寫死結果。
- 上一步、重來、暫停及減少動態偏好沿用第一課。固定動畫控制占位與 scrollbar-gutter，避免版面抖動。
- 最後一幕顯示「演示完成」，以明確按鈕進入理解題，再接下一課；合併沒有新觀察的重複結尾。課程地圖可自由回看，不使用固定展開的多欄目錄。

## 課程順序與實驗

| 階段           | 課程                     | 先看見／親手操作                                       | 之後才介紹                                  |
| -------------- | ------------------------ | ------------------------------------------------------ | ------------------------------------------- |
| 訂單如何成交   | 1. Maker、Taker 與 K 線  | 100 的淡線、掛 101、買到 101／110、賣回 99             | Maker、Taker、上影線                        |
|                | 2. 掛單與撤單            | 在 98 等待、撤回、最後主動成交                         | 限價單、報價與成交價                        |
|                | 3. 深度與滑價            | 厚盤買 3；重設成薄盤，再買相同數量                     | 最佳買賣價、深度、成交均價、滑價            |
|                | 4. 掛單牆                | 大量賣單擋在 101，撤走後才讓買單前進                   | 掛單牆、可見意願與成交證據                  |
| 成交留下什麼   | 5. Delta 與 CVD          | 先買 4，再賣 2，把兩側已成交量相減                     | Delta、區間與累計                           |
|                | 6. Footprint             | 留下不同價位的主動買賣，再把記錄排回價位               | Bid × Ask、對角失衡                         |
|                | 7. Volume Profile        | 在同價位反覆交換，將成交量疊成橫條                     | Profile、POC、觀察區間                      |
|                | 8. VWAP                  | 100 成交 1、104 成交 3，按份量平均                     | 加權均價，不是買賣訊號                      |
| 流動性如何改變 | 9. 冰山單                | 可見 1，買掉後又出現 1，再揭開保留量                   | 顯示量、隱藏量、補量                        |
|                | 10. 買單被吸收           | 三批各買 3；賣量 12 → 3，CVD 0 → +9，價格停在 101      | 主動買量增加不保證價格前進，賣單可持續承接  |
|                | 11. 流動性熱圖           | 逐次保存掛單畫面，撤單後新增一欄                       | 時間快照、色帶、成交與撤單的區別            |
| 合約與判讀     | 12. OI                   | 兩人新開、轉手、兩人平倉                               | 多空成對、成交量與未平倉量                  |
|                | 13. 資金費率與價差       | 認識多空部位；正費率付款、負費率反向；比較合約與參考價 | Funding、名義價值、永續溢價與到期基差的區別 |
|                | 14. 強制平倉與連鎖反應   | A 觸發後賣出消耗買單，標記價再下移觸發 B，B 又賣到更低 | 保證金不足、被迫賣出與深度消耗的連鎖因果    |
|                | 15. 用下一筆成交驗證判讀 | CVD +5、101 剩賣量 1 時先選判讀，再買 2 見證突破       | 從觀察提出假設，再依新成交修正              |

## 視覺與整合

直接沿用 `public/site.css` 的 MetaBear 色票：深藍黑 `#080e18`、青綠 `#78e1d5`、金色 `#e8bd7d`、次要文字 `#94a8b9`。保留目前學員已驗收的配置和留白，改成深色面板；買賣方向同時使用文字和顏色。

所有教學單元共享同一套外殼、課程地圖、理解題和本機完成紀錄。保留 `?lesson=` 深連結。情境實戰和即時市場作為完成教學後的工具入口，沿用既有功能，不在新生入口同時展示。

## 實作與驗證

- 以課程資料描述每幕內容、操作和逐步揭露的視圖；純模型以既有撮合引擎產生結果。
- 成交動畫逐檔演示，回放及上一步可由相同操作序列確定性重建。
- 深度比較、Footprint／Profile、VWAP、補量、OI 和資金費用做數值驗證。
- 瀏覽器逐課走完，驗證理解題、前後課切換、課程地圖、進度保存、手機與捲軸穩定。
- 本機驗收後再依使用者指示發布。
