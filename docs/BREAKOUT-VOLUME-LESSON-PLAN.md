# 放量突破，怎樣才算站穩？

40 秒市場故事。作為上一課「突破後高位掛賣吸收，再由主動賣出接手」的對照：放量突破104 → 上方持續交易 → 回踩104 → 被動限價買單吸收主動賣出 → 買方重新推升109。

核心問題：回踩時賣單很多，為什麼這次104沒有被打穿？

## 分鏡（先於模型確定）

| 秒數 | 同一段行情 |
| --- | --- |
| 0–4 | 十根已完成的一分K，標出突破、回踩104、再走向109；明示完整模擬行情回看。 |
| 4–7 | 沿同一座標放大目標區，7秒開始重播第5根；前五根背景固定，第5–9根只依已播放成交形成。 |
| 7–13 | 放量突破，103逐檔到106，成交120、Delta+100；前五根均量20，突破是6倍。 |
| 13–19 | 上方105–107持續成交，量120、Delta+80，收107。 |
| 19–22 | 主動賣出使107回到104，量100、Delta−80；104原有掛買80，先承接40，剩40。 |
| 22–30 | 104再承接240主動賣出，數次掛買補入；本根量260、Delta−220，CVD下降，但低點仍104。 |
| 30–36 | 後續主動買入逐檔成交105、106、107、108、109，量180、Delta+160，收109。 |
| 36–40 | 36–39秒退回同一份完整十根歷史，保留已發生的回踩與吸收，40秒結束。 |

- 第6根 O106/H107/L105/C107，量120、主動買100／賣20、Delta+80。
- 第7根 O107/H107/L104/C104，量100、主動買10／賣90、Delta−80。
- 第8根 O104/H105/L104/C104，量260、主動買20／賣240、Delta−220。104賣240／105買20，非零對角比值12倍。
- 第9根 O105/H109/L105/C109，量180、主動買170／賣10、Delta+160。
- 全段量880，主動買485／賣395，最終CVD90。前五根CVD50；後五根收盤CVD依序150、230、150、−70、90。期間峰值240。
- 104掛買初始80，回踩成交40後剩40；吸收段成交40歸零、補100、成交60與40、補80、成交50與30、補60、成交20，最後剩40。每一次補單與成交獨立記錄。

## 同一份事件帳本

所有成交有side、price、size、at、barIndex、fraction與x=barIndex+fraction。bar 5/6/7/8/9的播放範圍為7–13、13–19、19–22、22–30、30–36秒；每根對應一分鐘市場時間，動畫播放時長依故事重點壓縮。

OHLCV、各bar Delta、逐筆CVD、每價Bid/Ask足跡與熱圖全部由同一帳本重建。每筆成交消耗當時最優對手報價；add/cancel只變掛單，不改成交價、OHLC、成交量或CVD。熱圖分段反映未成交數量，不平滑捏造數字。足跡採對角3倍、對手格非零；3倍為本課選用門檻，不是市場通則。

開場與結尾是同一份完整已完成歷史。7秒明示回看後，前五根固定，後五根逐筆重建；跳幕、正反拖曳與減少動態模式皆共享純函式快照。

## 查證與研究邊界

- [Bookmap — Absorption Indicator](https://bookmap.com/knowledgebase/docs/KB-Indicators-Absorption)：被動限價買單可承接大量主動賣出。與上一課被動掛賣承接主動買入方向相反，本課不把主動賣量增加等同於價格必跌。
- [Fidelity — Support and Resistance](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/support-and-resistance)：突破後原壓力可以轉為支撐；本課具體演出104的回踩成交及掛買承接，不把角色互換當必然規則。
- [Sierra Chart — Numbers Bars](https://www.sierrachart.com/index.php?page=doc/NumbersBars.php)：Bid/Ask與相鄰價位對角比較。
- [Coinbase — Trading Rules](https://www.coinbase.com/legal/trading_rules)：主動成交逐檔匹配最優現有委託；新增與撤單本身不等於成交。

這是一個具體合成結果：成交量維持、回踩在104被承接、後續確實交易到109。不是「放量＋回踩必成功」條件，也不能辨認買賣方身分或持有量。CVD下降代表本段主動賣出較多，被動限價買方仍可能承接；不將CVD解讀為總資金流或某位交易者的部位。
