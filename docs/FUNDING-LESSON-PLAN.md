# 資金費率

名詞圖解 C12 · 本地桌面動態教材 · 32 秒。

一句目標：看見費率正負如何決定多空之間資金費的交換方向，以及交換金額來自部位價值。

## 具體模型

明示教學用 USDT 永續，依 Bybit 資金費機制。兩側持倉數量均為 100，兩次結算標記價格都設為 100 USDT，因此部位價值均為 10,000 USDT；此為合成條件，不是即時商品報價。

| 事件       |   費率 | 多方現金流 | 空方現金流 | 累計多方／空方 |
| ---------- | -----: | ---------: | ---------: | -------------- |
| 起始       | +0.01% |          0 |          0 | 0／0 USDT      |
| 第一次結算 | +0.01% |         −1 |         +1 | −1／+1 USDT    |
| 等待下一次 | −0.02% |   尚未入帳 |   尚未入帳 | −1／+1 USDT    |
| 下一次結算 | −0.02% |         +2 |         −2 | +1／−1 USDT    |

- 部位價值 = 結算持倉數量 × 結算標記價。
- 多方現金流 = −部位價值 × 資金費率；空方反向。正現金流代表收到。
- 未參與該次結算的持倉、數量為 0 或費率為 0 時，現金流為 0。
- 槓桿不另乘進公式；相同部位價值、不同槓桿設定，資金費金額相同。

「本段資金費收支」不是帳戶餘額、保證金，也不含交易價差損益或其他費用。模型每次由時間重新推導，回拖不會重複扣款。

## 邊界與官方來源

[Bybit — Funding Fee Calculation](https://www.bybit.com/en/help-center/article/Funding-fee-calculation) 核對了 USDT 部位價值公式、正負費率方向、結算持倉資格與不同合約的結算間隔。資金費在多空持倉者間交換，不畫成交易所收入。開場只說這是幫助永續價格靠近現貨的機制，不承諾必然貼合。

實際結算有處理時間；Bybit 特別說明時點前後數秒開平倉，不保證被納入或排除該次結算。本課使用已確定的持倉資格，不演示搶最後一秒平倉來免付費。費率生成算法、借貸利息、套利策略與保證金不足時的扣費流程不在本課範圍。
