# 黃金口袋，是答案還是巧合？

狀態：**已製作**，2026-10-05 加入 `academy-catalog.js`（`status: "new"`）與「走進行情裡面」路線。

核心問題：斐波那契回調線很多人用，它到底有沒有用？如果有，有用的是 0.618 這個比例，還是別的東西？

定位：市場故事，不是策略。刻意不做「回到 0.618 就進場」，避免和 T02（到價承接）、T03（回調結束訊號）重複；本課回答「為什麼這些線有時候看起來有用」，並把學員帶回 T02 的結論：線給地點，成交給答案。

先修（不強制）：熱力圖、停損單、同一道支撐，守住或翻轉。

## 調研摘要

1. **比例本身沒有顯著的統計優勢。** 對外匯 9 個貨幣對 2003–2016 年一分鐘資料的回測，找出 40,243 次超過 15% 的回調：回調深度呈平滑的對數常態分布，在斐波那契比例上沒有特別集中；約 83% 落在 15%–61.8%，而這段剛好放了四條斐波那契線，碰到某條線多半是巧合。[Forexop — Fibonacci Retracement: Is it a Myth or Reality?](https://forexop.com/strategy/fibonacci-fact-or-fiction/)
2. **更早的回測結論相同。** Merrill（1977, *Filtered Waves*）對大量股票測試，38%、50%、62% 的回調並沒有比其他比例更常出現。[Wikipedia — Fibonacci retracement](https://en.wikipedia.org/wiki/Fibonacci_retracement)、[ResearchGate — Automatic identification and evaluation of Fibonacci retracements](https://www.researchgate.net/publication/354702159_Automatic_identification_and_evaluation_of_Fibonacci_retracements_Empirical_evidence_from_three_equity_markets)
3. **它有時有用，是因為「大家都在看」。** 加密市場常見把 0.618–0.65 稱為黃金口袋，很多人在這裡掛限價買單、停損放在 0.786 下方；這就是 T02 引用 Osler 研究的掛單聚集機制：停利與承接單集中處容易反彈，停損集中處一被越過就加速。[Quantum Algo — Golden Pocket](https://www.quantum-algo.com/blog/fibonacci-golden-pocket-trading/)、[LuxAlgo — Golden Pocket](https://www.luxalgo.com/library/concept/golden-pocket/)
4. **常見教法本身也要求重疊其他依據**（前高前低、POC、訂單塊），等於承認線本身不夠。

## 帳本與口徑

- 合成熊、元、隻；K 線以價格路徑 `[[t, p], …]` 表示，OHLC 由路徑推導；`tests/orderflow-motion.test.mjs` 的帳本測試核對下列數字。
- **波段**：低點 1,000、高點 2,000；`fibPrice(r) = 2000 − 1000 × r`。
- **上漲 8 根**（O/H/L/C）：1000/1080/990/1070、1070/1200/1060/1180、1180/1330/1170/1310、1310/1450/1290/1430、1430/1600/1410/1580、1580/1720/1560/1700、1700/1860/1690/1840、1840/2000/1820/1980。
- **共用回調 5 根**：1980/1990/1880/1900、1900/1920/1760/1780、1780/1800/1640/1660、1660/1680/1520/1540、1540/1560/1420/1440。
- **模擬回調深度**（10%–90%，每 5%）：4、9、14、19、22、23、22、20、17、14、11、9、7、5、3、1，共 200；單峰、無斐波那契尖峰；15%–65% 共 171 次。
- **人群掛單**：1,382 掛買 250、1,370 掛買 200、1,355 掛買 150（黃金口袋合計 600）；1,500 掛買 60。多單停損 1,200，共 400 隻。
- **A**：第 14 根路徑 1440 → 1450 → 1382（成交 150）→ 1370（成交 120）→ 1355（成交 80）→ 1380 → 1420；吸收 350，低點 1,355（回調 64.5%，在黃金口袋內）。之後 1420/1520/1410/1510、1510/1640/1500/1630。
- **B**：到價前撤 200、160、120（剩 120）；第 14' 根 1440 → 1445 → 1382 → 1370 → 1355（吃掉剩下的 50、40、30）→ 51.6 秒到 1,214、觸發停損 → 1,150 → 1,190 → 1,180；下一根 1180/1230/1150/1160。
- 黃金口袋、0.786 停損位置、掛單數量都是常見做法的示意；200 次回調是教學用模擬，真實統計引用 Forexop 回測，不代表任何市場的機率。
