# 成交量分布圖

2026-09-24｜名詞圖解 13｜30 秒桌面本地教材。前置：成交量、K 線。

目標：看見同一批已成交資料，從「每分鐘多少」重新分成「每個價位多少」，並知道 POC 只描述選定範圍內成交最多的位置。

## 分鏡

| 播放時間 | 動作與焦點                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 0–4 秒   | 三根已完成的分鐘 K 線，下方量柱為 40、60、40。標示統計範圍 14:30–14:33、總成交 140 隻。                                            |
| 4–13 秒  | 同場景放大，第一根的 100×10、101×20、102×10 依次離開時間量柱，移至右側對應價位。每個片段改變位置和形狀，數量不變。第二根開始加入。 |
| 13–23 秒 | 其他分鐘繼續按同價位歸類。每次只有一個移動片段；待歸類、移動中、已歸類三個數字清楚區分。21.3 秒全部歸類，橫向合計仍為 140。        |
| 23–30 秒 | 101 元的 60 隻最長，標示 POC。鏡頭拉回原場景，保留 K 線與完成的橫向分布；收尾一句說明是已成交量，不是等待掛單。                    |

固定下方單句提示；數字直接使用精確事件值，只有鏡頭和圖形位置做插值。

## 同一批資料

合成商品 MetaBear 熊，單位元／隻，每列寬度為 1 元。不區分主動買賣方向，橫向統計總成交量。

| 價位 | 14:30–14:31 | 14:31–14:32 | 14:32–14:33 | 按價位合計 |
| ---- | ----------: | ----------: | ----------: | ---------: |
| 103  |           0 |          20 |           0 |         20 |
| 102  |          10 |          20 |          10 |         40 |
| 101  |          20 |          20 |          20 |     **60** |
| 100  |          10 |           0 |          10 |         20 |
| 合計 |      **40** |      **60** |      **40** |    **140** |

- 三組成交帶依序為 `100×10 → 101×20 → 102×10`、`101×20 → 102×20 → 103×20`、`102×10 → 101×20 → 100×10`，K 線直接由各帶的價格順序推導。
- 九個矩形片段對應九筆教材成交，依次按價位重新分組。它們是已完成資料的搬移，沒有產生九筆新成交。
- 每個片段只有一個狀態：尚在來源、正在移動、已抵達價位。出發時扣來源，抵達時加目的地；移動途中不算入任一端。每個片段只繪製一次。
- 始終滿足 `待歸類 + 移動中 + 已歸類 = 140`。例如 6.5 秒為 `130 + 10 + 0`；來源欄內數字是尚待歸類的數量，歸零不表示原分鐘沒有成交。
- 右側長度使用固定線性比例，140 這個成交總量不隨鏡頭或統計方式改變。POC 僅在全部歸類後標出，避免把未完成分組的暫時最大值當最終 POC。
- 綠色只服務數量分組和 POC 強調，不代表圖中的量全是主動買入。沒有價值區、未成交掛單、支撐或行情預測推論。

## 官方依據

TradingView 官方說明 Volume Profile 是指定期間內、按價位整理的交易活動；POC 是該期間成交量最大的價位。其輸入亦可依平台選擇不同資料與列寬。[Volume profile indicators: basic concepts](https://www.tradingview.com/support/solutions/43000502040-volume-profile-indicators-basic-concepts/)

本教材固定使用已知逐筆價格與數量、三分鐘範圍、1 元列寬，避免把特定平台的低週期估計方式當成所有圖表的共同規則。
