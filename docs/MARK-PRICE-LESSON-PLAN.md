# 標記價格

> 2026-09-24 依使用者回饋移除。本卡片與模型僅保留為製作紀錄；課程不再列入地圖，舊網址返回學院。

名詞圖解 10 · 本地桌面動態教材 · 30 秒。

一句目標：分清最近一筆撮合的成交價，與用於風險估值的標記價格。

## 分鏡

| 時間     | 主畫面                                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 0–6 秒   | 同一張價格圖，暖金成交價與薄荷綠標記價原本相近。左右各有大數字，先辨認成交價的來源。                                               |
| 6–15 秒  | 同場景放大。8.5 秒出現 92 元低價成交，標記價為 99.8，兩條線拉開；11 秒成交 94.5，標記 99.5。                                       |
| 15–24 秒 | 14.5 秒成交 99.2、標記 99.4，再次靠近。下方逐步接出「多市場指數等參考 → 標記價格 → 風險估值」。18.5 秒提示此平台依標記價判定強平。 |
| 24–30 秒 | 拉回完整紀錄。後續兩價也同步下移至約 98.8／98.9，讓標記價不是固定值這件事直接可見。結語：風險估值的尺，不是保證成交價。            |

不重教槓桿、不加入強平金額計算。可接到「合約強平」，兩課仍可獨立自由選看。

## 資料與界線

行情均為明示的合成觀測值，用來展示用途，**不是平台標記價公式的計算回放**。成交價與標記價為兩條獨立資料序列，沒有把標記價偽造為「成交價平均」或簡單平滑線。兩條序列只在明確事件更新，攝影機／高亮可以連續移動，數字不插值。

| 播放秒數 | 最後成交 | 標記價格 |
| -------- | -------: | -------: |
| 0        |      100 |      100 |
| 1.8      |    100.2 |      100 |
| 3.2      |    100.2 |    100.1 |
| 4.6      |    100.1 |   100.05 |
| 8.5      |       92 |     99.8 |
| 11       |     94.5 |     99.5 |
| 14.5     |     99.2 |     99.4 |
| 19       |     99.6 |     99.5 |
| 23.5     |     98.8 |     98.9 |

選用 Bybit 永續合約作為機制來源：標記價參考現貨價格指數、基差／資金等資料，且其機制也可能使用最後成交價。實際算法會依商品、資料品質、平台規則調整。因此課程不聲稱標記價完全不受成交價影響、不聲稱一定較平滑或永遠不受衝擊；本例只示範一次短暫偏離。標記價沒有成交保證，真實成交仍依實際撮合。
