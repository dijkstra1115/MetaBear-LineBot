# 合約槓桿

名詞圖解 06 · 桌面動態教材 · 30 秒 · 2026-09-24。

一句承諾：看懂保證金如何對應部位，以及損益實際跟著部位數量與價差變化。

## 分鏡

| 時間     | 畫面與理解                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–6 秒   | 兩條同場景的部位軌道。各放 100 元保證金；1 倍對應一格、5 倍對應五格，每格 1 隻、開倉價 100 元。                                                    |
| 6–16 秒  | 鏡頭靠近五格部位。8.5 秒價格由 100 到 101，每格 +1，共 +5；12.5 秒改為 99，每格 −1，共 −5。上軌道同期為 +1／−1。                                   |
| 16–24 秒 | 拉回兩條軌道。19.5 秒明確改為另一組開倉設定比較：1 倍、500 元保證金與 5 倍、100 元保證金，兩者同為五隻。不是在 99 元實際加倉；不模擬部位調整成交。 |
| 24–30 秒 | 24.5 秒兩組同遇 101 元，皆 +5 元。保證金報酬率分別 +1% 與 +5%，損益金額相同，停在完整對照圖。                                                      |

## 資料與假設

教學用線性做多合約。報價為合成教材，開倉價固定 100 元；忽略交易費與資金費。部位價值統一指開倉時名目金額，不冒充即時市值。只在標示報價事件變更數字；鏡頭、淡入、事件高亮可連續移動。

- 開倉部位價值 = 保證金 × 槓桿。
- 部位數量 = 開倉部位價值 ÷ 開倉價。
- 未實現損益 = 部位數量 ×（目前價格 − 開倉價）。
- 剩餘權益 = 保證金 + 未實現損益；保證金報酬率 = 損益 ÷ 保證金。

本課不解釋強平機制；另提供強平專課。用「一隻的合約曝險」避免讓學員把合約理解成已持有現貨。
