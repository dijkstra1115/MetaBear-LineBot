# 合約強平

名詞圖解 07 · 本地桌面動態教材 · 32 秒 · 本次重修。

一句目標：看懂 **500 元部位的下跌，如何吃掉 100 元保證金**。先讓跌 5% 虧 25、跌 10% 虧 50 的比例關係一眼成立，再用短結尾區分強平與理論歸零點。

## 分鏡

| 時間     | 主畫面                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 0–6 秒   | 100 元保證金經 5× 連向五格開倉值各 100 元的部位；總開倉部位 500 元。下方保證金條保持 100 元。                                |
| 6–15 秒  | 同場景靠近。8 秒市場跌 5%，五格各損失 5 元，下方保證金條吃掉四分之一：已虧 25、剩 75。14 秒跌 10%，各虧 10：已虧 50、剩 50。 |
| 15–24 秒 | 保持大數字與保證金條。19 秒跌 15%，虧 75。22.5 秒本例在約跌 19.6% 達強平門檻，凍結部位演算。                                 |
| 24–32 秒 | 26 秒鏡頭拉回完整比例圖。以虛線小註記標出「−20%：只是假設不強平的歸零點」。不把已強平部位繼續虧到 20%。                      |

每格金額與總部位值均指 **開倉時名目金額**；實際數量固定五隻合約。主要畫面不引入最後成交價、權益曲線或完整維持保證金公式。

## 模型與精確邊界

教學用 **線性逐倉做多合約**，開倉價 100 元、數量 5、保證金 100 元、開倉部位 500 元。忽略交易費、資金費，無額外補入保證金、風險分層扣減。維持率假設 0.5%，畫面只以短圖例註明；並非任何平台所有商品的通則。依標記價判定。

- 損益 = 5 ×（標記價 − 100）。
- 保證金剩餘權益 = 100 + 損益。
- 維持門檻 = 5 × 標記價 × 0.5%。
- 精確強平價格 = (500 − 100) ÷ [5 × (1 − 0.5%)] = 80.40201005025126。
- 對應跌幅約 19.59799%，畫面簡記 **19.6%**；觸發時剩餘權益約 2.01 元。
- 假設沒有提早強平時，100 − 100 ÷ 5 = 80 才是保證金算式歸零點，即跌 20%。此點 **只作反事實對照，不是本課實際報價事件**。

所有金額以完整精度計算、顯示至二位小數；整數不額外加小數。觸發只用原始值，1e-9 為浮點等值誤差。播放遇第一次觸發便凍結，即使日後追加資料也不再延伸該部位。終點是強平觸發畫面，不是實際結算或可取回款項。
