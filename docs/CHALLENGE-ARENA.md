# FLOW ARENA：爆倉獵場 V5

執行 `npm run preview:academy`，開啟 `http://127.0.0.1:8790/orderflow/challenge.html`。目前是桌面試玩版（最小寬度 1180px，手機上會顯示提示），市場與帳戶都在瀏覽器本機模擬，沒有真實交易，也沒有公開排行榜。

## 核心玩法

玩家資金大到足以撼動市場。市場裡有帶槓桿的散戶，他們的強平價畫在圖上的「爆倉熱圖」：亮帶越亮，代表該價位的強平量越大。

- 推穿亮帶，該價位的散戶就得市價平倉。強平單繼續推價，碰到下一條亮帶再引爆，每秒推進一波。
- 推不到亮帶，或亮帶太薄，造市商會把價格慢慢拉回，推價的成本就由你承擔。
- 有些亮帶前面藏著護盤者的冰山單；推上去只會被吸收，然後被拉回。
- 獵手也在獵亮帶；你的部位太重時，它會改獵你的強平價。

熱圖上的每條亮帶都只是「看起來」值得推。玩家要自己判斷：燃料夠不夠、推得到嗎、有沒有人守、別人是不是已經先推了、什麼時候該走。

## 讀盤工具與策略

| 判斷 | 可用的公開資訊 |
| --- | --- |
| 值不值得推 | 爆倉熱圖、燃料雷達、下單預覽「依可見掛單推到哪裡、穿過多少強平」 |
| 有沒有人守 | 切到「掛單熱圖」找亮帶前面不動的掛單線；圖上的金色「疑似冰山」線（某價位 45 秒內成交 ≥ 8 BTC，而且是目前掛出量的 3 倍以上）；Footprint 在同一價位堆出大量成交 |
| 推下去之後 | 預估推動和實際推動差太多時，會顯示「推不動！」並說明被吸收 |
| 什麼時候走 | 爆倉跑馬燈的連環次數；連環停下後造市商會拉回 |
| 會不會被獵 | 圖上的「你的強平」線與錢包裡的強平價；曝險越高、越近越危險 |

用機器人驗證過的有效策略（40 個種子）：

| 策略 | 平均報酬 | 勝率 |
| --- | --- | --- |
| 盲目推價 40 BTC、2 秒後平倉 | −3.0% | 0% |
| 只看熱圖，推最亮的亮帶、持有 3 秒 | −0.4% | 35% |
| 連環爆倉（≥2 波）停下後反手 25 BTC | +0.3% | 55% |
| 讀盤：避開疑似冰山、先用 10 BTC 試探、推不動就撤，搭配爆倉後反手 | +0.4% | 70% |

讀盤高手的報酬分布：中位數 +0.44%、前 25% +1.3%、前 10% +2.2%。人類玩家若加上部位大小與時機判斷，可以做得更好。評級據此校準：S ≥ 200 分（約報酬 2%）、A ≥ 100、B ≥ 40、C > 0。

## 操作與規則

- 每局 120 秒。開局前先模擬 150 秒歷史，K 線、掛單、散戶持倉都由撮合自然形成；另有 3–4 群「前段被套」的大型槓桿倉，強平價在開盤價上下約 0.9–2.9%。
- 標的是從 100,000 USDT 起始的模擬 BTC/USDT 永續合約。起始資金 **10,000,000 USDT**；**1 單位＝1 BTC**，起始權益約等於 100 BTC 名目。
- 下單數量 10／25／50／100 BTC；市價買賣，或點圖表價格掛限價單。玩家限價單不會過期，直到成交或撤單。
- 快捷鍵：Q 買、E 賣、F 平倉、1–4 切換數量、空白鍵暫停。
- 可設定觸價止損／止盈。平倉永遠吃到成交：造市商在 1–4.5% 外保留後備深度；只有連後備深度都被吃完，剩餘部位才會在下一秒重試。
- 權益跌到持倉名目的 6% 時強制平倉，本局失格。
- 得分為 `max(0, 淨報酬率 %) × max(0, 1 − 最大回撤率 / 20%) × [1 / (1 + max(0, 最高曝險率 − 100%) / 100%)] × 100`，取整數。

### 模式

- **新市場**：隨機種子，結算前不顯示種子。
- **每日市場**：用本機日期產生種子，同一天所有人打同一個市場。
- **影子挑戰／重玩此市場**：同種子重玩，並顯示對手或上一局的分數與權益路徑。

## 市場參與者

- **散戶流**：每秒約 10 筆、每筆 1 BTC，在最新價 ±0.4% 內出價；現價下方為賣、上方為買，能撮合就成交，留在簿上的單 30–55 秒後過期。約 28% 的散戶成交會變成槓桿持倉（10／20／25／50 倍），部分帶止損或止盈；散戶持倉每秒自然平掉約 1.2%。
- **追價與逆勢散戶**：價格突破近 30 秒高低點時，追價者以市價開倉；價格偏離合理價 0.7% 以上時，逆勢者反向開倉。
- **造市商**：兩側 12 層報價，近價（0.8% 內）約 28 BTC、遠處後備約 112 BTC。報價會留在簿上保有排隊順序：每秒數次檢查，被吃掉的量每次補回約三成；只有偏離目標太遠（超過該層距離的 35%）或尺寸不符時才撤掉重掛。報價中心慢慢靠向合理價，超出本局價值帶 2% 後拉得更用力；強平潮進行中先退開、暫停回拉；單邊主動量大時擴大價差、減少近價掛單。
- **隱藏大戶**：按自己的目標方向分批執行。被動掛單離價格超過 1.2% 或掛超過 25 秒就撤單，未成交量回到待執行目標。
- **護盤者**：每群被套大倉有 65% 機率被守住。在強平價前 0.2–0.5% 藏一筆冰山單，總量為該群倉位的 0.9–1.8 倍，簿上只露 2–4 BTC；被吃掉就在同一價位補量，直到藏量用完（吃穿）或價格遠離 3% 才撤。
- **獵手**：跟玩家看同一份熱圖與可見委託簿。找「亮帶量 ≥ 推到那裡所需量 1.1 倍」的目標，最多動用 40 BTC 推價，2–4 秒後平倉，冷卻 16–26 秒。玩家部位 ≥ 30 BTC、強平價在 2.2% 內時，也會把玩家的強平價列為目標。它也會撞上冰山。
- **快訊**：每 24–34 秒一次。方向型快訊會讓一群追價散戶開倉，散戶報價略微偏向；流動性枯竭時近價掛單只剩 15–25%。

## 盤後複盤

結算頁包含：

- **教練筆記**：挑本局最貴的三個錯誤，每種問題至少一條。會標出的錯誤有：撞上冰山、滑價太大、出場太晚、推了卻沒引爆、被獵手盯上、被強平。
- **每一段持倉**：從開倉到平倉記為一段，列出部位、損益、引爆量、撞冰山量、滑價成本，以及最佳浮盈對比出場時的報酬。
- **盤後揭曉**：每個護盤者的位置、藏量、吃掉多少（其中多少是你的單）、最後被吃穿、撤退或守住；獵手出手次數、目標與損益；大戶的方向。

## 簡化與界線

- 散戶的強平與止損以**最新成交價**觸發，讓推價效果即時可見；玩家的止損與強平以**標記價**（非玩家最佳買賣價中點）判斷。
- 爆倉熱圖是模擬散戶持倉的實際強平價，精確度高於真實市場的估算工具；停損位置不顯示。
- 冰山單補量時保留原本的排隊位置；真實交易所的冰山單通常每次補量都重新排隊。
- OI 只計模擬散戶持倉與玩家部位，不代表完整市場。
- 散戶持倉的自然平倉不送出委託單；只有強平、止損與止盈會成為市價單。

## 影子挑戰

成績保存在此瀏覽器的 `localStorage`（V5 與舊版分開）。結果頁可複製包含種子、影子分數與權益路徑的連結。朋友會面對相同的初始市場與隨機序列，但玩家委託會改變後續簿面、散戶持倉與獵手行為，走勢不保證相同。連結沒有伺服器驗證，尚不適合正式排行榜。

## 驗證

執行 `npm run test:flow-arena`。測試涵蓋時間 K 線、造市商後備深度與排隊保留、冰山單補量與公開偵測、護盤者與揭曉、大戶撤單、獵手獵亮帶與玩家強平價、強平價公式、推穿亮帶的強平歸屬、每秒一波的連環爆倉、無人跟進時的價格回拉、流動性枯竭時的平倉、持倉紀錄與教練筆記、同種子重現，以及固定 24 個種子的平衡驗收：盲推平均虧 1.5% 以上、只追熱圖為負、讀盤策略為正，且讀盤比只追熱圖至少高 0.4 個百分點。
