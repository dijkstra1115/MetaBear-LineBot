# FLOW ARENA：爆倉獵場 V4

執行 `npm run preview:academy`，開啟 `http://127.0.0.1:8790/orderflow/challenge.html`。目前是桌面試玩版（最小寬度 1180px），市場與帳戶都在瀏覽器本機模擬，沒有真實交易，也沒有公開排行榜。

## 核心玩法

玩家資金大到足以撼動市場。市場裡有帶槓桿的散戶，他們的強平價畫在圖上的「爆倉熱圖」：亮帶越亮，代表該價位的強平量越大。

- 推穿亮帶，該價位的散戶就得市價平倉。強平單繼續推動價格，碰到下一條亮帶再引爆，形成連環爆倉。
- 推不到亮帶，或亮帶太薄，造市商會把價格慢慢拉回，推價的成本就由你承擔。
- 下單區即時預覽「這筆單會推到哪裡、會穿過多少強平」；會穿過明顯亮帶時，預覽會亮起。
- 連環爆倉每秒推進一波。追著強平潮持有 2–5 秒再出場，通常比立刻平倉好；太晚出場，價格會被拉回。

## 操作與規則

- 每局 120 秒。開局前先模擬 150 秒歷史，K 線、掛單、散戶持倉都由撮合自然形成；另有 3–4 群「前段被套」的大型槓桿倉，強平價在開盤價上下約 0.9–2.9%。
- 標的是從 100,000 USDT 起始的模擬 BTC/USDT 永續合約。起始資金 **10,000,000 USDT**；**1 單位＝1 BTC**，起始權益約等於 100 BTC 名目。
- 下單數量 10／25／50／100 BTC；市價買賣，或點圖表價格掛限價單。玩家限價單不會過期，直到成交或撤單。
- 快捷鍵：Q 買、E 賣、F 平倉、1–4 切換數量、空白鍵暫停。
- 可設定觸價止損／止盈。平倉永遠吃到成交：造市商在 1–4.5% 外保留後備深度，流動性枯竭時也不會全撤，但滑價可能很痛。只有連後備深度都被吃完，剩餘部位才會在下一秒重試。
- 權益跌到持倉名目的 6% 時強制平倉，本局失格。圖上會畫出「你的強平」價位。
- 得分為 `max(0, 淨報酬率 %) × max(0, 1 − 最大回撤率 / 20%) × [1 / (1 + max(0, 最高曝險率 − 100%) / 100%)] × 100`，取整數。評級：S ≥ 250、A ≥ 120、B ≥ 50、C > 0。Maker 費率 0.02%，Taker 費率 0.05%。

## 市場參與者

- **散戶流**：每秒約 10 筆、每筆 1 BTC，在最新價 ±0.4% 內出價；現價下方為賣、上方為買，能撮合就成交。約 28% 的散戶成交會變成槓桿持倉（10／20／25／50 倍），部分帶止損或止盈。散戶持倉每秒自然平掉約 1.2%。
- **追價與逆勢散戶**：價格突破近 30 秒高低點時，追價者以市價開倉，止損放在突破點外；價格偏離合理價 0.7% 以上時，逆勢者反向開倉。
- **造市商**：兩側 12 層報價，近價（0.8% 內）約 28 BTC、遠處後備約 110 BTC，每秒重掛數次。報價中心會慢慢靠向「合理價」（價格的慢速平均），超出 2% 的「本局價值帶」後拉得更用力。強平潮進行中，造市商先退開、暫停回拉，所以爆倉的價格能撐一下；單邊主動量大時會擴大價差、減少近價掛單。
- **隱藏大戶**：按自己的目標方向分批執行，結算後揭曉。
- **快訊**：每 24–34 秒一次。方向型快訊會讓一群追價散戶開倉，並略微偏移散戶報價；流動性枯竭會讓近價掛單只剩 15%。

## 簡化與界線

- 散戶的強平與止損以**最新成交價**觸發，讓推價效果即時可見；玩家的止損與強平以**標記價**（非玩家最佳買賣價中點）判斷。真實交易所的強平通常用標記價，觸發方式也各不相同。
- 爆倉熱圖是模擬散戶持倉的實際強平價，精確度高於真實市場的估算工具；停損位置不顯示。
- OI 只計模擬散戶持倉與玩家部位，不代表完整市場。
- 散戶持倉的自然平倉不送出委託單；只有強平、止損與止盈會成為市價單。

## 平衡驗收

`tests/flow-arena.test.mjs` 以 16 個固定種子驗證：盲目推價再平倉平均虧損超過 1%，找大型亮帶推穿並持有 3 秒的策略平均獲利，兩者相差 1.5 個百分點以上。調參時的參考結果（30 個種子）：

| 策略 | 平均報酬 |
| --- | --- |
| 盲目推價 40 BTC、2 秒後平倉 | −2.4% |
| 每 10 秒隨機多空 25 BTC | −1.1% |
| 看快訊方向下單 | +0.6% |
| 推穿 ≥20 BTC 亮帶、持有 2–5 秒 | +0.8% 至 +1.2% |

2 分鐘價格區間中位數約 9–10%，大多來自看得見的連環爆倉。平倉 50 BTC 空單的平均滑價：平時約 2.6%、流動性枯竭時約 2.7%，均能一次成交。

## 影子挑戰

成績保存在此瀏覽器的 `localStorage`（V4 與舊版分開）。結果頁可複製包含種子、影子分數與權益路徑的連結。朋友會面對相同的初始市場與隨機序列，但玩家委託會改變後續簿面與散戶持倉，走勢不保證相同。連結沒有伺服器驗證，尚不適合正式排行榜。

## 驗證

執行 `npm run test:flow-arena`。測試涵蓋時間 K 線、造市商後備深度、強平價公式、推穿亮帶的強平歸屬、每秒一波的連環爆倉、無人跟進時的價格回拉、流動性枯竭時的平倉、玩家強平價、同種子重現，以及上述平衡驗收。
