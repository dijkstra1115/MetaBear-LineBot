# FLOW ARENA：爆倉獵場 V6

執行 `npm run preview:academy`，開啟 `http://127.0.0.1:8790/orderflow/challenge.html`。目前是桌面試玩版（最小寬度 1180px，手機上會顯示提示），市場與帳戶都在瀏覽器本機模擬，沒有真實交易，也沒有公開排行榜。和朋友連線對戰見 `FLOW-ARENA-PVP.md`（頁面 `/orderflow/arena.html`）。

## 核心玩法

玩家資金大到足以撼動市場。市場裡有帶槓桿的散戶，圖上的「爆倉熱圖」估計他們的強平價：亮帶越亮，估計的強平量越大。熱圖是**估算**，不是散戶的真實倉位（見〈熱圖是估的〉）。

- 推穿亮帶，該價位的散戶就得市價平倉。強平單繼續推價，碰到下一條亮帶再引爆，每秒推進一波。簿面太薄、強平單當下吃不完時，剩下的部位每秒繼續市價平倉直到歸零，價格被拉回也不會「復活」。
- 推不到亮帶，或亮帶太薄，造市商會把價格慢慢拉回，推價的成本就由你承擔。
- 有些亮帶前面藏著護盤者的冰山單；推上去只會被吸收，然後被拉回。
- 獵手也在獵亮帶；你的部位太重時，它會改獵你的強平價。

熱圖上的每條亮帶都只是「看起來」值得推。玩家要自己判斷：亮帶是不是真的、燃料夠不夠、推得到嗎、有沒有人守、別人是不是已經先推了、什麼時候該走。

### 熱圖是估的

熱圖的算法跟真實的清算熱圖工具一樣是推估：每一筆主動成交（公開的強平單除外）都假設有 30% 開了槓桿倉，槓桿依 10／25／50／100 倍的常見分布攤開，估計的倉位每秒淡出 0.8%，價格走過的價位視為已經強平。開局前就被套的大倉會以模糊的位置和大小出現，有一半的局還會留下一條其實已經沒人的舊亮帶。

所以熱圖會錯在這些地方，而這些錯誤都能從其他指標看出來：

| 熱圖怎麼錯 | 從哪裡看出來 |
| --- | --- |
| 大波動之後放量，多半是平倉，熱圖卻當成新倉畫出一堆亮帶 | OI 下跌（圖表下方藍線） |
| 盤整時量小，散戶卻悄悄加槓桿，真實的倉位比熱圖多 | OI 上升 |
| 一群人用同一個槓桿集中疊倉，真實亮帶更集中、更亮 | OI 急升＋主動單一面倒（CVD） |
| 大戶、獵手或其他玩家的大單也被當成新倉 | 量很大但 OI 沒跟著動 |
| 亮帶前面有人用冰山單守著 | Footprint 在同一價位堆出大量成交、價格推不動 |

散戶的開倉比例也隨盤勢改變：30 秒內波動超過 1.2% 時，額外的成交量大多是平倉（開倉比例 5%，持倉加速離場）；區間小於 0.4% 時，開倉比例升到 45%。熱圖工具不知道這件事，永遠假設固定比例。

## 讀盤工具與策略

| 判斷 | 可用的公開資訊 |
| --- | --- |
| 亮帶是不是真的 | OI（圖表下方藍線）在放量時有沒有跟著漲；CVD 是否一面倒 |
| 值不值得推 | 爆倉熱圖、燃料雷達、下單預覽「依可見掛單推到哪裡、熱圖估計穿過多少強平」（都是估算） |
| 有沒有人守 | 切到「掛單熱圖」找亮帶前面不動的掛單線；Footprint 在同一價位堆出大量成交（圖上不再自動標出冰山） |
| 推下去之後 | 你自己的成交只推到預估的六成以下時，會顯示「推不動！」並說明被吸收（只看你的成交，不受你觸發的散戶止盈、止損影響） |
| 什麼時候走 | 爆倉跑馬燈的連環次數；連環停下後造市商會拉回 |
| 會不會被獵 | 圖上的「你的強平」線與錢包裡的強平價；曝險越高、越近越危險 |

用機器人實測的策略階梯（300 個種子，機器人只看玩家看得到的資訊；`npm run lab:flow-arena -- --seeds 300` 可重跑，改動 NPC 後用它檢查有沒有冒出壓倒性打法）：

| 策略 | 平均報酬 | 勝率 | S 率 |
| --- | --- | --- | --- |
| 盲目推價 2,000 BTC、2 秒後平倉 | −3.2% | 2% | 0% |
| 雙邊掛單當造市商 | −1.8% | 2% | 0% |
| 跟著成交紀錄的主動方向追 | −0.5% | 14% | 0% |
| 20× 盲推（受風險限額限制，只能開 1,000 BTC） | −0.1% | 9% | 0% |
| 只看熱圖：讀疊在一起的亮帶，出場單掛在連鎖盡頭外並反手 | −0.1% | 46% | 16% |
| 同上，用 3× 開到 4,000 BTC | −0.1% | 45% | 21% |
| 預掛兩倍出場單＋分批推過去 | 0.0% | 45% | 3% |
| 試探、避開冰山、推完 3 秒走，並在連環爆倉停下後反手 | 0.0% | 48% | 7% |
| 連環爆倉停下後反手 | +0.2% | 57% | 3% |

只看熱圖的機械式打法大約打平，沒有任何一種壓倒其他打法；盲推明顯虧損。我們還沒能用機器人證明「對照 OI 讀盤」能穩定贏過只看熱圖（試過的兩種 OI 機器人都沒有明顯優勢），這要靠真人試玩確認。

實際玩家憑判斷挑盤、抓時機可以打出 +3.5%（S 338 分）。評級：S ≥ 200 分（約報酬 2%）、A ≥ 100、B ≥ 40、C > 0。


高槓桿不是無腦最優解：部位沒放大時槓桿只影響保證金；想靠 20× 把部位放大，會先撞上風險限額。大部位要用低槓桿、押更多保證金，爆掉時的回撤也更大。

## 操作與規則

- 每局 120 秒。開局前先模擬 150 秒歷史，K 線、掛單、散戶持倉都由撮合自然形成；另有 3–4 群「前段被套」的大型槓桿倉，強平價在開盤價上下約 0.9–2.9%。
- 標的是從 100,000 USDT 起始的模擬 BTC/USDT 永續合約。起始資金 **500,000,000 USDT**，起始權益約等於 5,000 BTC 名目。引擎以 1 單位＝50 BTC 計算，讓近價深度接近主流交易所 BTC 永續（±1% 每側約 1,000–2,500 BTC），畫面一律顯示 BTC。
- 下單數量 500／1,250／2,500／5,000 BTC；市價買賣，或點圖表價格掛限價單。玩家限價單不會過期，直到成交或撤單。
- 快捷鍵：Q 買、E 賣、F 平倉、H 平一半、1–4 切換數量、空白鍵暫停。
- **自成交防護**：你的單碰到自己的反向掛單時，撤掉那筆掛單而不是跟自己成交（等同交易所的 expire maker）。
- 可設定觸價止損／止盈。平倉永遠吃到成交：造市商在 1–4.5% 外保留後備深度；只有連後備深度都被吃完，剩餘部位才會在下一秒重試。
- 得分為 `max(0, 淨報酬率 %) × max(0, 1 − 最大回撤率 / 20%) × 100`，取整數。

### 槓桿與保證金（逐倉、單一倉位）

- 同一時間只有一個淨部位。槓桿可選 1／3／5／10／20 倍（預設 3 倍，會記住上次的選擇），只能在**空倉且沒有掛單**時調整。
- **風險限額**：參考主流交易所的槓桿分級，部位越大、可用槓桿越低。20× 最多 1,000 BTC、10× 2,500 BTC、5× 5,000 BTC、3× 8,000 BTC、1× 不限（只受保證金限制）。計算時把會開倉的掛單一起算進去（掛單全部成交後可能達到的最大部位），只減倉單不算。
- 開倉或加倉前檢查保證金：需要「新增部位名目 ÷ 槓桿」的可用保證金。掛出去的限價單也會預留保證金，不能用掛單繞過上限。不足時拒單，並提示「最多還能開 X BTC」。
- 可用保證金＝錢包餘額 − 倉位保證金 − 掛單預留。浮動獲利不能拿來加倉。
- **逐倉強平**：倉位虧到只剩維持保證金（名目的 0.4%）時，以市價強制平倉，最多只賠掉這筆倉位的保證金（滑價超出的部分由保險基金吸收）。其他資金不受影響，這局繼續。強平價約在進場價反向 `1/槓桿 − 0.4%`：20 倍約 4.6%、10 倍約 9.6%、5 倍約 19.6%、1 倍幾乎不會爆。
- **只減倉**：勾選後，反向單最多平到零，不會反向開倉；掛出去的只減倉單在空倉時自動撤掉，合計超過部位的部分會被修剪。「平倉」「平 ½」「平 ¼」都走只減倉。
- 錢包顯示槓桿與倉位保證金、可用保證金、還能開多少 BTC、強平價，以及保證金使用率。

### 模式

- **新市場**：隨機種子，結算前不顯示種子。
- **每日市場**：用本機日期產生種子，同一天所有人打同一個市場。
- **影子挑戰／重玩此市場**：同種子重玩，並顯示對手或上一局的分數與權益路徑。
- **對戰電腦**：標題列的「對手」選單可選單人、新手、中階、高手各 1 人，或混合 3 人（各難度一位）。選擇會記住，重玩與影子挑戰連結沿用同一組對手。

### 對戰電腦

電腦對手和你在同一個市場交易，只看得到公開資訊，走同一套保證金、風險限額與強平規則。程式在 `public/orderflow/flow-arena-bots.js`，每秒在市場前進前各行動一次。

| 難度 | 對手 | 槓桿 | 風格 |
| --- | --- | --- | --- |
| 新手 | 死抱不放 | 20× | 順著前 20 秒方向進場、不停損，抱到賺 2% 為止；強平價一直在射程內 |
| 新手 | 莽撞推手 | 10× | 每 20 秒盲推一次 |
| 中階 | 快訊追手 | 20× | 順著方向型快訊進場、持有 8 秒 |
| 中階 | 反手客 | 10× | 連環爆倉停下後反手 |
| 中階 | 埋伏者 | 5× | 亮帶外預掛兩倍出場單，分批推過去 |
| 高手 | 讀盤手 | 3× | 讀疊在一起的亮帶，出場單掛在連鎖盡頭外 |
| 高手 | 重倉手 | 3× | 同上，開到 4,000 BTC |

同一難度用哪一位由種子決定。

- **市場隨人數放大**：2、3、4 人時，每單位分別代表 75、100、125 BTC（`ARENA_MARKET_SCALE`），造市深度、散戶單、爆倉帶的 BTC 量跟著放大，價格行為不變；每人起始資金、風險限額、下單按鈕的 BTC 數不變，所以單一玩家推動市場的力道變小，推同一條亮帶要更多人、更多錢。
- **對手強平價公開**：對手有倉位時，他的強平價以紫色虛線畫在圖上，只標「對手強平」，不標名字與部位；在畫面外時固定在圖表上緣或下緣，標出方向與距離。
- **爆倉跑馬燈**：對手被強平顯示「玩家多單／空單被強平」，是你推價期間發生的會標「你推爆」。對手推價引爆的散戶強平算在對手身上，不算「你引爆」。
- **結算**：顯示名次、每人得分與報酬、被強平次數；對戰紀錄列出誰推爆了誰、誰吃了誰的掛單與均價。

## 市場參與者

- **散戶流**：每秒約 10 筆、每筆 50 BTC，在最新價 ±0.4% 內出價；現價下方為賣、上方為買，能撮合就成交，留在簿上的單 30–55 秒後過期。約 28% 的散戶成交會變成槓桿持倉（10／20／25／50 倍），部分帶止損或止盈；散戶持倉每秒自然平掉約 1.2%。
- **追價與逆勢散戶**：價格突破近 30 秒高低點時，追價者以市價開倉；價格偏離合理價 0.7% 以上時，逆勢者反向開倉。
- **造市商**：兩側 12 層報價，近價（0.8% 內）約 1,400 BTC、遠處後備約 5,600 BTC。報價會留在簿上保有排隊順序：每秒數次檢查，被吃掉的量每次補回約三成；只有偏離目標太遠（超過該層距離的 35%）或尺寸不符時才撤掉重掛。報價中心慢慢靠向合理價，超出本局價值帶 2% 後拉得更用力；強平潮進行中先退開、暫停回拉；單邊主動量大時擴大價差、減少近價掛單。
- **隱藏大戶**：按自己的目標方向分批執行。被動掛單離價格超過 1.2% 或掛超過 25 秒就撤單，未成交量回到待執行目標。
- **護盤者**：每群被套大倉有 65% 機率被守住。在強平價前 0.2–0.5% 藏一筆冰山單，總量為該群倉位的 0.9–1.8 倍，簿上只露 100–200 BTC；被吃掉就在同一價位補量，直到藏量用完（吃穿）或價格遠離 3% 才撤。
- **獵手**：跟玩家看同一份熱圖與可見委託簿。找「亮帶量 ≥ 推到那裡所需量 1.1 倍」的目標，最多動用 2,000 BTC 推價，2–4 秒後平倉，冷卻 16–26 秒。玩家部位 ≥ 1,500 BTC、強平價在 2.2% 內時，也會把玩家的強平價列為目標（20 倍逐倉的強平價在約 4.6% 外，10 倍約 9.6%，通常要先虧一段才會進入獵手範圍）；玩家部位 ≥ 4,000 BTC 時，不論強平價多遠，都會反向推 1% 試著逼你出場。它也會撞上冰山。
- **群聚開倉**：開盤後每 16–24 秒一次（最後 25 秒不會出現），一群順勢交易者朝過去 30 秒的方向、用同一個槓桿（25 或 50 倍）在 6–10 秒內分批市價進場，共 1,000–2,000 BTC。進場過程會在成交紀錄上留下連續同向的主動單，熱圖上會長出一條新亮帶，讓後半場也有燃料。
- **快訊**：每 24–34 秒一次。方向型快訊會讓一群追價散戶開倉，散戶報價略微偏向；流動性枯竭時近價掛單只剩 15–25%。

## 盤後複盤

結算頁包含：

- **教練筆記**：挑本局最貴的三個錯誤，每種問題至少一條。會標出的錯誤有：撞上冰山、滑價太大、出場太晚、推了卻沒引爆、被獵手盯上、倉位被強平。
- **複製本局數據**：把本局設定、每一筆下單（含槓桿、只減倉）、每段持倉、權益曲線和複盤輸出成 JSON，複製到剪貼簿（無法寫入時改為下載檔案），方便貼給教練或 AI 逐筆分析。
- **每一段持倉**：從開倉到平倉記為一段，列出部位、損益、引爆量、撞冰山量、滑價成本，以及最佳浮盈對比出場時的報酬。
- **盤後揭曉**：每個護盤者的位置、藏量、吃掉多少（其中多少是你的單）、最後被吃穿、撤退或守住；獵手出手次數、目標與損益；大戶的方向。

## 簡化與界線

- 散戶的強平與止損以**最新成交價**觸發，讓推價效果即時可見；玩家的止損與強平以**標記價**（非玩家最佳買賣價中點）判斷。
- 爆倉熱圖是估算（見〈熱圖是估的〉）；真實的強平分布只在引擎內部與測試中使用，停損位置不顯示。
- 冰山單補量時保留原本的排隊位置；真實交易所的冰山單通常每次補量都重新排隊。
- OI 只計模擬散戶持倉與玩家部位，不代表完整市場。
- 散戶持倉的自然平倉不送出委託單；只有強平、止損與止盈會成為市價單。

## 影子挑戰

成績保存在此瀏覽器的 `localStorage`（V6 與舊版分開），對戰電腦的成績會標出對手難度。結果頁可複製包含種子、影子分數與權益路徑的連結。朋友會面對相同的初始市場與隨機序列，但玩家委託會改變後續簿面、散戶持倉與獵手行為，走勢不保證相同。連結沒有伺服器驗證，尚不適合正式排行榜。
