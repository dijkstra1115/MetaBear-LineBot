# Orderflow Academy · 訂單流沉浸式教學

## 產品規劃（先於實作）

目標：使用者能操作訂單、解釋成交如何形成價格，並以觀察 → 假設 → 行動 → 回顧的流程應用訂單流。繁體中文為主，保留業界英文術語。入口 `/orderflow/`，獨立於 CRM 與正在開發的量化收集器。

### 學習與互動架構

1. **市場全貌**：價格、成交量、CVD、OI；看見事件的整體效果。
2. **成交足跡**：按價格分組的 Bid × Ask、Delta、成交量分布與 POC；點擊價格可深入。
3. **訂單簿內部**：逐價掛單、主動成交、佇列、冰山補量；操作同一市場模型，縮放不重設狀態。

每課包含概念、明確操作、可觀察結果、常見誤判與一道理解題。保留進度，允許自由跳課。以少量預設情境降低第一次操作的負擔，再開放完整下單控制。

### 課程範圍

| 單元                   | 操作與觀察                                         |
| ---------------------- | -------------------------------------------------- |
| 撮合與 spread          | 市價買入消耗 Ask，市價賣出消耗 Bid                 |
| 深度與滑價             | 相同訂單在不同流動性下的成交均價                   |
| 限價與撤單             | 掛入自己的委託，再撤銷，觀察 CVD 不變              |
| Delta 與 CVD           | 不同方向的主動成交，累計值與價格分歧               |
| 冰山單                 | 小量顯示、逐次補量；模擬器揭露真實隱藏量           |
| 吸收與耗竭             | 重複吃單但價格停滯，以及量能不足的情境             |
| Footprint 與 imbalance | 每價 Bid × Ask 與對角不平衡                        |
| Volume Profile 與 POC  | 由成交重建分布、最大成交價                         |
| VWAP                   | 量加權均價與成交後的移動                           |
| OI                     | 雙方開倉／雙方平倉／換手的三種變化                 |
| 掛單牆與撤單           | 顯示流動性可以消失，無法直接判定操縱意圖           |
| 資金費率與基差         | 費率方向、計算示例與 mark/index 的區別             |
| 清算與連鎖反應         | 被迫主動成交造成的流動性消耗                       |
| 流動性熱圖             | 每側 12 檔快照隨時間形成色帶，掛單牆撤離後色帶消失 |
| 綜合判讀               | 價格 × CVD × OI，建立有失效條件的假設              |

### 實戰

- 情境演練：固定種子的合成事件、未來不可見、逐步推進，先記錄方向／證據／失效條件，再揭露與回顧。
- 紙上交易：持倉、成交均價、費用、已實現與未實現損益；只能使用已揭露的盤面成交。以固定小額部位作為練習，不接真實交易權限。
- 真實市場：Bybit BTCUSDT / ETHUSDT 公開 WebSocket：orderbook.50、publicTrade、tickers、allLiquidation。具 snapshot/delta、成交 ID 去重、重連清空與資料過期提示。
- 錄製回放：使用者主動錄製當次真實行情，將有上限的取樣快照保存／匯出 JSON，再從起點逐步回放。明示這是取樣教學回放，非完整逐筆 L2 檔案；既有 quant collector 仍負責完整原始資料。

### 指標語義與資料誠實性

- CVD = 主動買量 − 主動賣量的累計，BTCUSDT 用 BTC、ETHUSDT 用 ETH。真實模式自連線起計；斷線後重啟區段，不暗中拼接。
- 教學 OI 採單邊未平倉合約量；Bybit 同時可能提供 singleOpenInterest 與雙邊 openInterest，明確正規化與標註。
- 掛／撤單不改變成交量或 CVD。公開 L2 的減量不能單憑差分當成成交。
- 模擬模式的冰山有已知隱藏量；真實模式不宣稱能辨識委託者、隱藏量或意圖。
- Footprint、Profile、VWAP 限於已接收／當次事件視窗，不冒充全市場或完整交易日。
- 清算串流 S 為被清算的持倉方向，p 為破產價格，不能當作逐筆成交價。
- 實戰評量聚焦證據和風控，情境答案不構成獲利保證。

### 視覺與 UX

石墨黑工作空間、偏白文字、螢光黃綠作為教學焦點，買賣另外用青綠／珊瑚紅並附文字。採側邊課程地圖、中央共享市場視圖、右側教練與操作台、底部事件時間軸。縮放以連續的視覺定位與前進／返回按鈕保持方向感。尊重減少動態設定，不攔截瀏覽器縮放。窄螢幕改成單欄，所有功能保留；鍵盤焦點、錯誤回饋、可取消動作與資料來源始終清晰。

### 工程切分與驗收

1. 純 ES module 撮合引擎及數值測試。
2. 教材、三層 SVG 視圖、下單與互動任務。
3. 實戰／紙上帳本與回放，Bybit 唯讀行情轉接。
4. Worker 路由與僅此頁的 WebSocket CSP；既有業務不變。
5. 引擎測試、型別檢查、桌面／手機瀏覽器實測、WebSocket 實測、錯誤與斷線狀態檢查。

本階段不宣稱生產等級持久行情服務：瀏覽器關閉即停止收集；歷史逐筆訂單簿需提前錄製；教學模擬佇列不能保證真實交易所成交順位。

## 實作與啟動

已實作 15 個單元、3 層縮放、價格／熱圖切換、委託撮合、進度與理解題、3 組未知行情情境、紙上帳本，以及 BTCUSDT／ETHUSDT 真實行情錄製與取樣回放。

- 獨立本機預覽：`node scripts/orderflow-preview.mjs`，開啟 `http://127.0.0.1:8790/orderflow/`。預覽不依賴 CRM 或資料庫，僅監聽 127.0.0.1。
- 既有 Worker：`/orderflow` 轉向 `/orderflow/`；`/orderflow/` 提供此頁。既有學習中心側欄已加入入口。
- 純前端模組：`public/orderflow/`，不需額外安裝套件或打包。
- 核心測試：`node --test tests/orderflow.test.mjs`。
- 路由測試：`npx tsx --test tests/orderflow-routing.test.ts`（也納入既有 `npm test`）。
- 型別檢查：`npm run check`。

### 驗收紀錄

- 核心撮合、限價、冰山補量與 FIFO、OI 三種情況、VWAP／CVD、紙上反向部位及費用、回放資料隔離、Bybit snapshot/delta／去重／清算語義、錄製檔驗證：14 個測試通過。
- Worker 路由、課程 query 保留、頁面專屬 WebSocket CSP、既有頁面 CSP 不變：3 個測試通過。
- 桌面瀏覽器：引導下單、課程進度、三層縮放、冰山揭露與 4 次補量、完整 17 個盤面演練、紙上交易及回顧均實際操作。
- Bybit BTCUSDT 與 ETHUSDT 公開主網皆成功連線；實際紙上成交；錄製 37 個 BTC 真實快照，轉入回放並逐步揭露成功。手動斷線後確認紙上成交停用。資料沒有提交至第三方交易介面。
- 390px 手機及 768px 平板檢查無橫向溢出；手機提供圖表內直接實驗按鈕，減少往返操作台的捲動。已支援減少動態偏好。
- 資金費率正負切換及 Mark／Index 溢價滑桿均驗證。
- 沉浸模式可收起課程側欄與說明，保留共享圖表及操作台；同一按鈕或 Esc 返回。已驗證桌面切換沒有水平溢出。

### 目前邊界

目前已完成可使用的教學工作台，尚未發布到遠端。帳本、學習進度與日誌限本機瀏覽器；紙上帳本與未匯出錄製在重整後不保留。錄製檔以 JSON 主動匯出，最多 300 張快照（約 5–6 分鐘），非完整 L2 逐筆歷史。沒有模擬真實保證金、槓桿、延遲、資金費扣款或交易所佇列順位。實戰每個新盤面只允許一次成交，以避免同一盤面深度重複使用；行情過期或斷線會暫停成交。
