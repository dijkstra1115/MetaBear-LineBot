## 2. 美股錢流平台

- 目標：讓美股投資人一直回來看，不做成教學。用產業關係圖當骨架，疊上每天的事件。
- 回訪鉤子：今日錢流圖（依漲跌上色加一句話原因）、財報季連動、長期追蹤圖表（例如雲端四巨頭資本支出）、自選股。
- 推播：盤後摘要每天固定一則；重大事件只推給關注者，每人每天 1～2 則；財報後推一則。
- 第一版：AI 錢流圖，約 10 家公司（TSM、NVDA、AMD、AVGO、MSFT、AMZN、GOOGL、ORCL…）。
- 資料：可沿用 `C:\Users\style\code\sec-edgar` 的 SEC EDGAR、Benzinga、Finnhub、8-K 偵測與 LLM 判官。台積電申報 20-F，需要另外處理。
- 轉換：公司卡上放「在 BingX 交易」按鈕（BingX 有美股）。
- 待確認：
  - 資料授權目前是個人用途，若要對外公開展示，需確認條款是否涵蓋。
  - 台灣投顧法規：只能呈現事實與新聞，不給買賣建議或目標價。

## 4. 訊號通知（符合條件就通知）

- 2026-10-12：偵測規劃見 [ORDERFLOW-SIGNALS-PLAN.md](ORDERFLOW-SIGNALS-PLAN.md)。

- 想法：多個指標同時符合時，自動透過 LINE 通知。
- 可沿用：`src/signals.ts` 已有分析師報單的發送與媒體流程，以及 LINE 分群推播。
- 待想清楚：
  - 要用哪些指標與條件，條件是否需要先回測。
  - 自動訊號和分析師人工報單怎麼區分。
  - 免責聲明與法規界線。
  - 加密貨幣與美股要分開處理：美股訊號較可能碰到投顧法規。
- 2026-10-12 方向更新：走「分析不喊單」路線，每日劇本加隔日對答案；分析、自動訊號與過往紀錄都放在自己的網站上。
- 2026-10-12 資料可行性（實測公開 API，不需要 API Key）：
  - Footprint／CVD：幣安、Bybit、OKX、BingX 都有逐筆成交，含主動買賣方向。幣安 `data.binance.vision` 有歷史逐筆資料。
  - OI 與多空比：各家都有。幣安 REST 只保留最近 30 天，但 `data.binance.vision` 的 metrics 檔有 2020 年至今、每 5 分鐘一筆的資料。
  - 掛單熱力圖：只有即時掛單簿，歷史資料只有 ±1～5% 的彙總深度，所以要自己長期錄製。
  - 爆倉：幣安推播每秒只給一筆快照，資料不完整；Bybit 的 `allLiquidation` 會推全部；OKX 有 REST 和 WebSocket。
  - 爆倉地圖：Coinglass 的爆倉地圖是模型估算，不是交易所資料，要自己用 OI 和槓桿假設估算。
  - 基礎設施：需要一台常駐的資料收集器（VPS 或 Durable Object），並要測試幣安是否封鎖美國 IP。
- 2026-10-12 BTC 原型（分支 `feat/orderflow-lab`）：`npm run lab:orderflow -- --days 3` 下載幣安歷史封存檔，產生 `public/lab/data/btcusdt.json`（不進版控）。頁面在 `/lab/orderflow/`，有足跡圖、POC、斜向不平衡、成交量分布（含 POC 和價值區）、CVD、OI、大戶持倉比與全體多空比。已確認幣安 metrics 檔的 `sum_toptrader_long_short_ratio` 就是 API 的大戶持倉比。
