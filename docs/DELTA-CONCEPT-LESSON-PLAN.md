# Delta 與 CVD

2026-09-24｜名詞圖解 09｜30 秒桌面本地教材。前置：足跡圖、成交量。

目標：用同一組已完成成交，分清每段的主動買賣量差與從明確起點累計的差。

| 播放時間   | 畫面與短句                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–4 秒     | 三個已完成的一分鐘足跡，同一套左主動賣、右主動買讀法。                                                                                                   |

| 18–30 秒   | 下方出現明示的「14:30 歸零」起點，CVD 依次累加為 25、15、30。每段 Delta 和累積收盤點共用水平位置。結尾停在完整足跡／Delta／CVD，提示不是人數或方向保證。 |

## 資料與假設

- MetaBear 熊、元、隻是合成教材。使用方向已知的成交帶，不用小周期漲跌來估算買賣方向。
- 14:30–14:31：101 元主動買 20、主動賣 15，102 元主動買 20；買 40、賣 15、總量 55、Delta +25。
- 14:31–14:32：102 元主動買 10、101 元主動賣 20；總量 30、Delta −10。
- 14:32–14:33：101 元主動賣 10、102 元主動買 25；總量 35、Delta +15。
- CVD 自指定的 14:30 歸零開始：0＋25＝25；25−10＝15；15＋15＝30。跨分鐘延續，不把每根 CVD 又歸零。不同圖表的起點與重置設定可能不同，不能脫離設定比較絕對值。
- 圖中 CVD 是各分鐘收盤值連線，不宣稱呈現逐筆路徑。數字直接揭示精確值，鏡頭與物件可以移動，數字不做假中間值動畫。
- Delta 不是成交總量，也不是買方減賣方的人數。每筆成交仍有買賣雙方，這裡分類的是主動方向。正值不保證價格上漲。
- 四幕與單句字幕，30 秒自動播完，可反向回拖、減少動態、重播。不沿用舊 Delta 市場故事。

## 一手依據

Sierra Chart 官方明確定義 Cumulative Delta 為 Ask Volume 與 Bid Volume 差值的累積，並說明逐根相加、重置到零的情形，以及起始時間會影響後續累計值。[Cumulative Delta Bars – Volume](https://www.sierrachart.com/index.php?ID=292&page=doc/StudiesReference.php)

本例的主動方向是合成逐筆成交的已知欄位；真實資料來源可能使用不同分類方法，課程不宣稱所有平台的計算輸入完全一致。

## 驗收

- 逐分鐘足跡合計必須等於各段買賣量，Delta 為買減賣，成交總量另為買加賣。
- 三段 CVD 分別 25、15、30；明示起點零與每分鐘收盤時間。
- 每次揭示邊界、回拖、減少動態及有限幾何以 `tests/orderflow-delta-concept.test.mjs` 驗證。
- 共用導覽、手機 fallback、瀏覽器視覺驗收與本地入口由主 Agent 整合；不部署。
