# MetaBear 願景與方向

2026-10-12 由使用者確認，同日依使用者回饋修訂。這是本專案最重要的核心方向。範圍與維護狀態仍以 [PROJECT-MAP.md](PROJECT-MAP.md) 為準；偵測器與內部回測細節見 [ORDERFLOW-SIGNALS-PLAN.md](ORDERFLOW-SIGNALS-PLAN.md)，想法來源見 [IDEAS.md](IDEAS.md)。

## 一句話

**用實戰勝利的電影級覆盤吸引人，帶他們到網站學課程、用交易軟體、訂閱警報，再把新的勝利交易拍成下一部覆盤。**

## 主循環

```
實戰打單獲勝的覆盤影片（吸引人）
        ↓
來網站學更多課程／使用訂單流交易軟體
        ↓
訂閱警報與訊號
        ↓
依策略打單、記錄每一筆交易
        ↓
挑出獲勝的交易，製作成新的電影級覆盤影片 ──→ 回到第一步
```

## 定位

- **分析，不喊單**：提供盤面事件、劇本與策略教學，不提供買賣指令。這是我們自己的原則，不需要在影片裡當口號講。
- **策略為本**：我們有多種策略（A、B、C…），每種策略看的指標與資料不同。影片與課程都圍繞「這個策略看什麼、為什麼進場、怎麼出場」。策略就是學院的「策略實戰」課：A＝策略 01「掃過前低，收回才算數」（失敗拍賣）、B＝策略 02「同一道支撐，守住或翻轉」、C＝策略 03「回調縮量，才是上車點」；之後新增的策略也先做成課程。候選策略 D：使用者以前實盤的「爆倉位突破收上影線，回測主動賣最大價位反向做空」，紀錄在 [STRATEGY-LIQ-WICK-FADE.md](STRATEGY-LIQ-WICK-FADE.md)。
- **主打特色**：有質感、沉浸式、像電影一樣的動畫覆盤，而不是截圖加文字。

## 四大支柱

| 支柱 | 目標 | 已有基礎 | 主要缺口 |
| --- | --- | --- | --- |
| **電影級實戰覆盤** | 挑出「某個策略在歷史上條件大致符合、照策略開單會獲利」的真實案例，具體呈現該策略所用指標與資料的變化和判斷邏輯 | 動畫引擎與 HyperFrames 影片流程、逐筆歷史資料、語音合成；覆盤短片 01 原型（`motion/replays/2026-02-06/`） | 策略定義、案例搜尋工具、交易紀錄格式、每種策略的視覺語言 |
| **訂單流交易平台** | 網站上的專業訂單流軟體：足跡、CVD、OI、多空比、熱力圖、爆倉、爆倉地圖、事件 | `/lab/orderflow/` 原型、即時直連交易所、本機收集器 | 常駐主機、帳號、手機版、效能、多幣種 |
| **警報與訊號訂閱** | 用戶訂閱多種盤面警報與策略訊號，推送到 LINE | LINE bot、CRM 標籤、推播佇列、事件偵測器 | 訂閱設定、推送管道、通知節流 |
| **課程與學院** | 每支覆盤影片都連回對應策略與指標的課程 | 23 堂動態課程、FLOW ARENA 沙盤 | 以策略為單位的課程地圖 |

## 不可妥協的原則

1. **不替用戶下結論**：內部回測可能有誤，不對外發布「我們驗證了某方法、結論是…」的內容，影片也不提回測。理由：數據太好，用戶照做虧錢會怪我們；數據太差，又會讓人不想學。回測只當內部工具，用來設計策略、挑選案例。
2. **案例要真實、可追溯**：覆盤影片用的都是真實歷史資料；每支影片的數字都要能回溯到原始資料。
3. **案例是教學，不是績效承諾**：影片呈現「這個策略在這個時間點怎麼判斷」，不宣稱勝率或報酬；每個案例都要畫出停損位置，教風險控管。
4. **事件不是指令**：警報描述「發生了什麼」，判斷留給使用者與分析師。
5. **法規**：不喊單；美股內容只呈現事實；所有頁面與影片附「非投資建議」。
6. **資料授權**：交易所資料的商用展示條款，在平台正式對外上線前確認（使用者負責）。
7. **沿用既有原則**：不把 LINE 使用者 ID 送到外部模型、不記錄對話內容、CSP 只開放必要的來源。

## 核心資產

- 訂單流專業與學院課程（23 堂動態課程）。
- 可重播、可渲染成影片的動畫引擎與 HyperFrames 影片流程。
- 資料管線：幣安封存檔、即時收集器（成交、掛單簿、三家交易所爆倉、OI 與多空比）。
- 事件偵測器與內部回測流程（只供內部設計策略與挑案例）。
- LINE 官方帳號、CRM、BingX 邀請碼自動核實。

## 內部研究摘要（不對外發布）

依據約一年的 BTCUSDT 永續資料，細節見 [ORDERFLOW-SIGNALS-PLAN.md](ORDERFLOW-SIGNALS-PLAN.md)：

- 單一偵測器以固定時間尺度衡量，沒有扣除成本後可交易的方向優勢。
- 吸收、掃蕩、背離在 15 分鐘到 1 小時內略優於隨機；放量突破後短線常回落；OI 異動之後波動放大。
- 尚未測試的關鍵問題：偵測器加上**策略的出場規則**（停損、目標、盈虧比）後的表現。之前的回測只看固定時間後的漲跌，不等於策略績效。

## 路線圖

每一階段都要能獨立上線。

| 階段 | 內容 | 完成的定義 |
| --- | --- | --- |
| 1. 第一個策略與第一部實戰覆盤 | 定義策略 A（情境、觸發、確認、進場、停損、出場）；做案例搜尋工具，從歷史資料找出策略 A 獲利的真實案例；挑一個拍成覆盤影片，畫面依策略 A 的指標呈現資料變化與判斷邏輯 | 影片公開發布，結尾導向網站與 LINE |
| 2. 覆盤劇場 | 交易紀錄格式（策略標籤、進出場、停損、截取當時資料）、網站互動覆盤播放器、同一份資料自動產出短影片 | 每一筆紀錄都能在網站重播，獲勝的可以一鍵產出影片素材 |
| 3. 正式平台與訂閱 | 收集器上常駐主機、帳號、手機版、警報與策略訊號訂閱（推送到 LINE） | 會員可以登入使用平台、訂閱並收到警報 |
| 4. 更多策略與變現 | 策略 B、C…各自的覆盤系列；例如透過 BingX 邀請碼註冊即解鎖進階警報與完整覆盤 | 轉換流程與 CRM 核實串接完成 |

## 與其他項目的關係

- **交易人格測驗**：拉新工具，導流到 LINE 與平台。
- **FLOW ARENA 沙盤**：讓使用者練習看盤，與覆盤劇場互補。
- **學院課程**：覆盤影片與警報都連回對應策略與指標的課。
- **研究內容**（「用過去 X 時間驗證 Y 方法」）：暫不做，見原則 1。
- **美股錢流平台**：暫緩，等主軸穩定後再評估。
