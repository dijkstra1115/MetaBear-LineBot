# MetaBear 願景與方向

2026-10-12 由使用者確認，是本專案最重要的核心方向。範圍與維護狀態仍以 [PROJECT-MAP.md](PROJECT-MAP.md) 為準；研究細節見 [ORDERFLOW-SIGNALS-PLAN.md](ORDERFLOW-SIGNALS-PLAN.md)，想法來源見 [IDEAS.md](IDEAS.md)。

## 一句話

**用實證內容吸引人，用專業的訂單流平台留住人，用電影級的覆盤讓每一筆輸贏都變成教學。**

## 定位

- **分析，不喊單**：提供盤面事件、劇本與覆盤，不提供買賣指令。
- **用實證說話**：每個說法都附上「用多長時間的資料、驗證了什麼、結果如何」，包括失敗的結果。
- **每一筆都公開**：策略和分析的輸贏全部記錄，不挑賺錢的單。
- **主打特色**：有質感、沉浸式、像電影一樣的動畫覆盤，而不是截圖加文字。

## 四大支柱

| 支柱 | 目標 | 已有基礎 | 主要缺口 |
| --- | --- | --- | --- |
| **研究內容** | 定期發布「我們用過去 X 時間，驗證 Y 方法，得到 Z 結論」 | 回測系統（`scripts/orderflow-backtest.mjs`），三段資料共約一年的驗證結果 | 對外的研究報告頁、短影片版本、發布節奏 |
| **訂單流交易平台** | 網站上的專業訂單流軟體：足跡、CVD、OI、多空比、熱力圖、爆倉、爆倉地圖、事件 | `/lab/orderflow/` 原型、即時直連交易所、本機收集器 | 常駐主機、帳號、手機版、效能、多幣種 |
| **警報與訊號訂閱** | 用戶訂閱多種盤面警報，推送到 LINE | LINE bot、CRM 標籤、推播佇列、事件偵測器 | 訂閱設定、推送管道、通知節流 |
| **電影級覆盤** | 每一筆紀錄都能重播成沉浸式動畫，可在網站互動播放，也能輸出成短影片 | 動畫課程引擎（`draw(ctx, t)` 可逐格重播與渲染）、逐筆歷史資料、語音合成、影片輸出工具 | 交易紀錄格式、覆盤播放器、運鏡與配樂設計 |

## 不可妥協的原則

1. **誠實**：不宣稱沒有驗證過的勝率；所有紀錄包含虧損；研究結論附上樣本大小與資料期間。
2. **事先登記**：新的訊號假設要先寫下規則與通過標準，再用沒看過的資料驗證；沒通過的就不上線，也照實公開。
3. **事件不是指令**：警報描述「發生了什麼」，判斷留給使用者與分析師。
4. **法規**：不喊單；美股內容只呈現事實；所有頁面附「非投資建議」。
5. **資料授權**：交易所資料的商用展示條款，在平台正式對外上線前確認（使用者負責）。
6. **沿用既有原則**：不把 LINE 使用者 ID 送到外部模型、不記錄對話內容、CSP 只開放必要的來源。

## 核心資產

- 訂單流專業與學院課程（23 堂動態課程）。
- 可重播、可渲染成影片的動畫引擎。
- 資料管線：幣安封存檔、即時收集器（成交、掛單簿、三家交易所爆倉、OI 與多空比）。
- 回測與樣本外驗證流程。
- LINE 官方帳號、CRM、BingX 邀請碼自動核實。

## 已驗證的研究結論（2026-10-12）

依據：90 天（2026-07-14 至 10-11）與另外 270 天的樣本外資料（2025-10-17 至 2026-07-13），BTCUSDT 永續、5 分鐘 K 棒，未扣手續費。細節見 [ORDERFLOW-SIGNALS-PLAN.md](ORDERFLOW-SIGNALS-PLAN.md)。

| 結論 | 證據 | 用途 |
| --- | --- | --- |
| 放量突破後短線常回落 | 15 分鐘內只有約 42% 延續突破方向，三段資料一致 | 研究內容；呼應進階 03 課「回踩承接才算站穩」 |
| OI 異動之後波動放大 | 比隨機時間多約 30～55%，三段資料一致 | 第一個「注意力警報」 |
| 吸收、掃蕩、背離在短線略優於隨機 | 15 分鐘至 1 小時命中率約 53～59%，但平均只有 1～2 bps | 盤感參考與教學，不適合機械式交易 |
| 機械式型態沒有可交易的方向優勢 | 十幾個偵測器 × 三種時間尺度；「強平區掃蕩」樣本外失敗 | 支持「分析不喊單」的定位；不宣稱勝率 |

## 路線圖

每一階段都要能獨立上線，帶來內容或收入。

| 階段 | 內容 | 完成的定義 |
| --- | --- | --- |
| 1. 旗艦作品 | 一部真實事件的覆盤短片（候選：2026-02-05 劇烈行情）＋第一篇研究報告（放量突破回落） | 短片與報告公開發布，取得第一批觀看與轉換數據 |
| 2. 覆盤劇場 | 交易紀錄格式、網站互動覆盤播放器、同一份資料自動產出短影片 | 每一筆紀錄都能重播，包括虧損的單 |
| 3. 正式平台 | 收集器上常駐主機、帳號、手機版、警報訂閱（先做 OI 異動，推送到 LINE） | 會員可以登入使用平台、訂閱並收到警報 |
| 4. 變現 | 例如透過 BingX 邀請碼註冊即解鎖進階警報與完整覆盤 | 轉換流程與 CRM 核實串接完成 |

## 與其他項目的關係

- **交易人格測驗**：拉新工具，導流到 LINE 與平台。
- **FLOW ARENA 沙盤**：讓使用者練習看盤，與覆盤劇場互補。
- **學院課程**：研究內容、警報與覆盤都連回對應的課。
- **美股錢流平台**：暫緩，等主軸穩定後再評估。
