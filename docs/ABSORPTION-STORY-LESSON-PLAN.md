# 一直有人買，為什麼漲不動？

2026-09-24｜市場故事 02｜36 秒桌面本地教材。前置：足跡圖、主動與被動成交。

目標：看見有限的被動掛賣能承接多筆主動買入；成交量增加，不代表最新成交價立刻上漲。

## 撮合與敘事邊界

- 沿用 `engine.js` 的撮合，使用獨立初始化市場：掛買 100×30；掛賣 101×80、102×20。
- 五次主動買入為 10、20、30、20、8；前四次均在 101，第五次 102。總成交 88，最後掛賣剩 12。每一筆成交的量與剩餘可見掛單守恆。
- 完全沒有補單、撤單、冰山或其他隱藏量。圖內明示「已知掛賣 80 · 沒有補單」。掛賣與足跡不同：前者等待，後者已成交。
- 第 20 秒清空 101 是一筆成交完成的結果；最新價仍是這一筆的 101。下一筆主動買入在第 26 秒才於 102 成交。兩事件分開，避免用鏡頭動畫或空檔捏造成交。
- 只說明這個已知模擬的機制。真實圖上不能從價格停留或足跡數字推論特定人的身份、意圖或是否存在隱藏單。也不宣稱出現吸收後必定反轉或突破。
- 「吸收」也可能由被動買方承接主動賣方；本課只演出賣方這一側，保持一課一個清楚例子。

## 一手依據

- Bookmap 官方將吸收說明為大量被動限價掛賣承接主動買入，或反方向由被動買單承接主動賣出；指標使用短時間同一價位的成交量。[Absorption Indicator](https://bookmap.com/knowledgebase/docs/KB-Indicators-Absorption)
- Bookmap 教學把同價位反覆成交、價格沒有移動作為觀察吸收的線索，並區分只看見大掛單與實際成交。[Layering and Absorption](https://bookmap.com/learning-center/order-flow-phenomena/order-flow-education/layering-and-absorption)

本課使用有完整掛單與成交紀錄的合成資料直接演示機制，不照搬來源中的進出場建議或人物意圖推測。

## 驗收

- 80→70→50→20→0 的同價掛賣消耗，對應 0→10→30→60→80 的已成交，價格一直 101。
- 下一筆 8 於 102，總成交 88，最終足跡是 101 買 80、102 買 8；沒有任何主動賣出。
- 價格、K 線、足跡、量條、掛單都從同一事件快照取得。回拖與減少動態偏好不改數據。
- 36 秒、自動連播、四幕、單句字幕、可全課回拖。以 `tests/orderflow-absorption-story.test.mjs` 驗證撮合、耗盡邊界、守恆、反向回拖、有限 SVG 幾何；主 Agent 統一瀏覽器驗收。不部署。
