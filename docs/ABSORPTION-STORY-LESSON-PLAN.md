# 突破誘多，高位吸收，反轉出貨

2026-09-24｜市場故事｜48 秒桌面版。吸收、突破、撤單三題合併成同一條行情，沿用 absorption-story ID。

## 固定資料與口徑

- 所有價格皆為合成 MetaBear 熊，最小跳動1元。前3根量各20、Delta各+10，作為同幅量尺的普通量基準。
- 3/4/5號測壓 K 成交量100/120/150，Delta+60/+80/+110，最高都是104；第5號 O103/H104/L103/C104。
- 全部9根共成交1140隻，主動買755、主動賣385，最終CVD370。高位第7號結束CVD610；第8號第一筆買10令CVD短暫到620，其後主動賣出主導，回落到370。
- 每筆成交與掛單事件都有時間、barIndex、fraction、x=barIndex+fraction；K、足跡、CVD與熱圖共用這一橫軸。
- 從空簿建立已知可見掛單，每筆成交必須消耗當刻最優對手報價。add/cancel/trade分開記帳，剩餘掛單不得負數、買賣盤不得交叉；取消及新增不產生成交或改變CVD。
- 高位106掛賣：開始100，突破階段成交60後剩40；接著買40，再補120、買70與50，再補100、買60與40，最後補80。第8號再買10後，106剩70。
- 對角不平衡採本課明示的3倍門檻：本格主動買(Ask)比較低一檔主動賣(Bid)；本格主動賣比較高一檔主動買。對手格必須非零，且比值至少3。3倍為本課設定，不是交易所通用法則。
- 前六根的開場是已完成歷史；從7秒重演5號起，後續6/7/8號只依實際播放到的事件形成，沒有提前顯示後續 K 或成交。

## 課名與對照課

依使用者審核更名「突破誘多，高位吸收，反轉出貨」。標題採市場敘事用語，指向本例突破後追買受困、再反轉的路徑；不新增單一參與者預先誘導或可由匿名圖形證明持倉的設定。畫面仍只一次標示「可能的出貨路徑」。下一課「放量突破，怎樣才算站穩？」以104掛買承接主動賣出、再由買單推高作對照。

## 研究來源與邊界

- [Bookmap — Absorption Indicator](https://bookmap.com/knowledgebase/docs/KB-Indicators-Absorption)：被動限價掛賣承接主動買入，或相反方向的被動買方承接。本課高位106的補量及成交都是明示的合成事件。
- [Sierra Chart — Numbers Bars](https://www.sierrachart.com/index.php?page=doc/NumbersBars.php)：Bid/Ask足跡及相鄰價位的對角比較。本課選擇3倍且分母非零，來源不提供普遍固定3倍法則。
- [Bookmap — Heatmap Main Chart](https://bookmap.com/knowledgebase/docs/KB-SettingUpAndOperating-HeatmapMainChart)：熱圖表示不同時間和價位的可見流動性。本課以逐筆add/cancel/trade重建，亮度只由該時段未成交數量決定。
- [Sierra Chart — Cumulative Delta Bars](https://www.sierrachart.com/index.php?ID=292&page=doc/StudiesReference.php)：Ask成交量減Bid成交量的累積。本例固定同一段累積起點，不把CVD解作資金流入或特定人的持倉。
- [Coinbase — Trading Rules](https://www.coinbase.com/legal/trading_rules)：成交與委託簿撮合規則；本課每筆主動成交只消耗當刻最優對手報價，撤單獨立記錄。
- [CME — Market by Order FAQ](https://www.cmegroup.com/articles/faqs/market-by-order-mbo.html)：即使提供逐筆委託深度，也維持委託者匿名。本課不將熱圖與主動成交方向連到同一個持有人。
- 課內收在「高位吸收後，主動賣出接手」，僅一次小標「可能的出貨路徑」。這組現象可以成為出貨的解讀線索，但匿名成交與委託深度不能證實不同時點由同一莊家操作，也不辨認持有人或持有量。本課不宣稱已證實出貨。
- 出貨也可能透過被動限價賣出完成，對手主動買入仍會令CVD上升；不需等到主動賣出占優才可能減少持有量。後段主動賣出只說明賣方更積極，不能證實與前段被動賣方是同一人。
- CVD是按主動成交方向加減的數量，不是某人的買賣或資金流；撤量不改CVD。熱圖只表示本例完整可見掛單，不暗示真實冰山或取消意圖。
