# 策略草稿：爆倉位突破收上影線，回測主動賣最大價位反向做空

狀態：使用者口述紀錄（2026-10-12），尚未寫成程式、尚未做成課程。使用者表示以前實盤用這個策略，績效很好。

## 使用者原話

> 特別觀察 M1、M5 的爆倉地圖，一旦某根 K 棒（假設 A）伴隨大額買單並且突破爆倉位，如果這時候有收上影線，則等下一根 K 棒價格回升到 A 中 footprint 主動賣量最高的地方，直接反向做空，止盈抓實盤 1%，止損也放實盤 −1%，也就是 1R。

## 整理成策略骨架

| 步驟 | 規則 |
| --- | --- |
| 週期 | M1、M5 |
| 地點 | 爆倉地圖上的爆倉位（空單強平密集的價位） |
| 事件 | K 棒 A 伴隨大額主動買，價格突破該爆倉位 |
| 確認 | K 棒 A 收上影線 |
| 進場 | 下一根 K 棒價格回升到 A 的足跡中**主動賣量最大的價位**時，限價做空 |
| 停損 | −1%（1R） |
| 停利 | +1%（1R） |

看起來也可以有多方鏡像（大額主動賣跌破多單爆倉位、收下影線、回測 A 中主動買最大價位做多），待使用者確認。

## 待使用者確認

1. 「實盤 1%」是指價格移動 1%，還是帳戶（含槓桿）損益 1%？
2. 「大額買單」怎麼判斷：主動買成交量、Delta，還是單筆大單？大約多少才算？
3. 「上影線」要多長才算：例如上影線佔整根 K 棒的比例？
4. 爆倉位以哪個來源為準：Coinglass 的爆倉地圖，或我們實驗室的預估爆倉地圖（`public/lab/orderflow/liqmap.js`）？兩者算法不同。
5. 下一根 K 棒沒有回升到該價位時，是否就放棄？M1 與 M5 是擇一使用，還是要同時符合？
6. 是否也做多方鏡像？

## 可行性備註

- 我們手上有 M1 足跡（主動買賣量依價位）、M5 K 棒，以及自己估算的爆倉地圖，可以寫成程式搜尋歷史案例。
- 我們的爆倉地圖是模型估算（OI 變化加上槓桿假設），和 Coinglass 不同，回測前要先確認兩者在關鍵爆倉位上是否大致一致。
- 停利停損都是 1R，扣掉手續費後需要勝率明顯高於 50% 才會賺錢；寫成程式後可以內部檢驗。
