# 策略草稿：爆倉位突破收上影線，回測主動賣最大價位反向做空

狀態：使用者口述紀錄（2026-10-12）。2026-10-21 起有研究用程式（`scripts/replay-cases/strategies.mjs` 的 `findD`），用來挑覆盤案例；尚未做成課程。使用者表示以前實盤用這個策略，績效很好。

## 使用者原話

> 特別觀察 M1、M5 的爆倉地圖，一旦某根 K 棒（假設 A）伴隨大額買單並且突破爆倉位，如果這時候有收上影線，則等下一根 K 棒價格回升到 A 中 footprint 主動賣量最高的地方，直接反向做空，止盈抓實盤 1%，止損也放實盤 −1%，也就是 1R。

## 整理成策略骨架

| 步驟 | 規則 |
| --- | --- |
| 週期 | M1、M5 |
| 地點 | 爆倉地圖上的爆倉位（空單強平密集的價位） |
| 事件 | K 棒 A 伴隨大額主動買，價格突破該爆倉位 |
| 確認 | K 棒 A 收上影線 |
| 進場 | 下一根 K 棒價格回升到 A 的足跡中**主動賣量最大的價位**時，限價做空 |
| 停損 | −1%（1R） |
| 停利 | +1%（1R） |

多方鏡像：大額主動賣跌破多單爆倉位、收下影線，下一根 K 棒回到 A 中主動買量最大的價位時限價做多。

## 已確認（2026-10-21）

- 多空都做（上面的多方鏡像）。
- 停損停利是**價格**移動 ±1%，不是帳戶損益。

## 待使用者確認

研究用程式目前先用括號裡的預設值：

1. 「大額買單」怎麼判斷：主動買成交量、Delta，還是單筆大單？大約多少才算？（主動買量高於前 48 根 M5 平均 2.5 個標準差，且 Delta 為正）
2. 「上影線」要多長才算：例如上影線佔整根 K 棒的比例？（反向影線 ≥ 整根 K 棒的一半）
3. 爆倉位以哪個來源為準：Coinglass 的爆倉地圖，或我們實驗室的預估爆倉地圖（`public/lab/orderflow/liqmap.js`）？兩者算法不同。（實驗室模型，取該方向爆倉量最大的 20 個價格格）
4. 下一根 K 棒沒有回升到該價位時，是否就放棄？M1 與 M5 是擇一使用，還是要同時符合？（放棄；只用 M5）

## 可行性備註

- 我們手上有 M1 足跡（主動買賣量依價位）、M5 K 棒，以及自己估算的爆倉地圖，可以寫成程式搜尋歷史案例。
- 我們的爆倉地圖是模型估算（OI 變化加上槓桿假設），和 Coinglass 不同，回測前要先確認兩者在關鍵爆倉位上是否大致一致。
- 停利停損都是 1R，扣掉手續費後需要勝率明顯高於 50% 才會賺錢；寫成程式後可以內部檢驗。
