核心問題：上漲途中價格往下回，這是趨勢在換氣、可以順勢上車，還是賣方已經接手、趨勢要結束？K 線長得很像，回調過程中的量、CVD、OI，以及回調結束時有沒有轉強，會給不同答案。

策略骨架沿用 T01／T02：**地點 → 事件 → 確認 → 執行**。先演 A（健康回調、順勢做多），倒帶回回調開始前演 B（換人了、不進場），最後並排對照。

先修（不強制）：Delta 與 CVD、未平倉量（OI）、成交量分布圖、同一道支撐，守住或翻轉。

## 調研摘要：順勢回調靠什麼判斷

1. **為什麼順勢：趨勢延續有長期證據，但不是每次都成立。** 58 種期貨跨資產研究發現「過去報酬預測未來報酬」的時間序列動能，約持續一年後部分反轉；這是月度尺度。日內與加密市場的證據較混合：比特幣高頻資料同時存在日內動能與反轉，哪個主導取決於跳空、流動性與事件。
   → 課內立場：**順勢只是預設方向，回調裡的成交才決定這次能不能上車**。[Moskowitz, Ooi & Pedersen (2012), Time Series Momentum](https://w4.stern.nyu.edu/facdir/lpederse/papers/TimeSeriesMomentum.pdf)、[Intraday return predictability in the cryptocurrency markets: Momentum, reversal, or both (2022)](https://www.sciencedirect.com/science/article/abs/pii/S1062940822000833)
2. **量：推升放量、回調縮量。** 健康的回調是推升的人在休息，成交量明顯低於推升段；回調量比推升還大，代表有人積極在賣。
3. **CVD：回調只吐回一部分。** 上升趨勢中，回調時 CVD 收斂、之後跟價格一起走高，是可以上車的回調；CVD 把推升段累積的買超全部吐回、跌破推升起點，代表賣方接手。CVD 只描述已發生的成交，不能單獨預測，需要價格結構配合。[Chart Whisperer — CVD Divergence](https://chartwhisperer.ca/blog/cumulative-volume-delta-cvd-crypto-trading-guide)、[ATAS — Session CVD Divergence Trap](https://learn.atas.net/volume-basics/volume-analysis/divergence-scale-and-workflow)
4. **OI：回調時是誰在動。** 價格跌、OI 跌 → 舊多單獲利了結，沒有新賣方進場；價格跌、OI 漲 → 新空單建倉，下跌有新資金支撐。所以健康回調是「價跌、OI 小降」，危險回調是「價跌、OI 增加」。[CoinSwitch — How to Read Open Interest](https://coinswitch.co/switch/crypto-futures-derivatives/open-interest-in-crypto-futures-india/)、[Quantum Algo — Open Interest Explained](https://www.quantum-algo.com/blog/guides/open-interest-explained-complete-guide/)
   - 修正先前口頭建議：不是「OI 沒減少才健康」，而是「回調時 OI 沒有增加（沒有新空單）才健康」。
5. **地點：推升段的成交中心，只是觀察區。** 推升段成交分布的 POC（成交最多的價位）是上漲途中雙方接受過的價格，回調常在附近結束；但本課**不在線上等承接**，它只告訴你「該開始注意了」。這是和 T02 的主要分工。
6. **觸發：回調結束的訊號。** 回調途中高點一路降低（下降的小結構）；回調以來第一根 Delta 轉正、接著突破回調的最後一個小高點，代表回調的下跌結構被打破，用突破進場（買進停止單的概念）。停損放在回調低點外。[Bookmap — Order Flow Strategies](https://bookmap.com/en/content/order-flow-strategies)
